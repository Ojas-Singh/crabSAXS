# Changelog

## 0.1.0 — 2026-08-08

Initial public release of CrabSAXS.

- Debye correctness reference and spherical-multipole fast path.
- PDB/mmCIF parsing with alternate-location, model, chain, water, HETATM,
  and glycan policies.
- Weighted experimental fitting with solvent, scale, and background controls.
- `calc`, `fit`, `score`, `ensemble`, `batch`, `inspect`, `compare`, and
  `info` commands with machine-readable output.
- Shared-solvent non-negative ensemble populations with pruning and seeded
  residual bootstrap intervals.
- Reproducible package metadata, CI, release archives, and checksums.
